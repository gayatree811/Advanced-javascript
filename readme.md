🔹 What is an Event?

👉 An event is something that happens in the browser.

Examples of events:

Clicking a button 🖱️

Pressing a key ⌨️

Moving the mouse

Page loading

Form submit

📌 In short:

Event = user action or browser action

🔹 What is an Event Listener?

👉 An event listener is code that waits and listens for an event to happen.

📌 In short:

Event listener = “When this happens, do this”

🔹 Simple real-life example

🛎️ Door bell

Bell rings → Event

You open the door → Event listener response
